# تحقق قارئ الصفحات المصوّرة — sv57

تم فتح نموذج PDF عام من مكتبة النماذج عبر زر «قراءة النموذج». ظهرت نافذة القراءة داخل الموقع، ثم عُرضت الصفحة الأولى من النموذج كصورة PNG داخل القارئ مع أزرار «السابقة» و«التالية» وترقيم الصفحة. استجابة صفحة القراءة أعلنت `Content-Type: image/png` وحملت توقيع PNG الصحيح، بينما قائمة الزوار لم تعد تحتوي على `fileUrl` أو `fileKey` أو `directUrl`.
