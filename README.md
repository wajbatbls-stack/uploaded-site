# واجبات بلس — الحزمة الكاملة القابلة للنقل

هذه الحزمة تشمل **واجهة الزائر** و**لوحة المالك المحمية** والخادم وقاعدة البيانات وطبقة رفع الملفات. لا تتضمن الحزمة ملفات الاعتماد الحقيقية أو مجلدات الاعتماديات أو ناتج البناء، ولذلك يمكن نقلها بأمان إلى خادم جديد ثم بناؤها في بيئته.

## مكونات الحزمة

| المكون | الموقع | الغرض |
|---|---|---|
| واجهة الزائر | `client/public` | الموقع العربي العام ونموذج تسليم الواجب. |
| لوحة المالك | `client/public/admin.html` | إدارة المحتوى والطلبات والرسائل والوسائط والإعدادات. |
| الخادم والواجهات البرمجية | `server` | الجلسات الآمنة وواجهات الإدارة والحفظ. |
| مخطط البيانات | `drizzle/schema.ts` | جداول المحتوى والعملاء والطلبات والرسائل والوسائط. |
| التخزين | `server/storage.ts` | التخزين المدمج أو S3 متوافق. |
| قالب الإعدادات | `config/environment.template` | قيم `KEY=value` نموذجية دون أسرار حقيقية. |
| توثيق النقل | `docs/DEPLOYMENT.md` | خطوات النشر التفصيلية. |

## البدء السريع

أنشئ متغيرات البيئة السرية في منصة الاستضافة أو في ملف البيئة المحلي وفق [قالب إعدادات البيئة](docs/ENVIRONMENT.example.md)، ثم استبدل كل القيم النموذجية بقيم الاستضافة وقاعدة البيانات والتخزين الخاصة بك. بعد ذلك، نفّذ الأوامر التالية داخل مجلد المشروع:

```bash
pnpm install --frozen-lockfile
pnpm db:push
pnpm build
NODE_ENV=production pnpm start
```

يستمع التطبيق إلى المنفذ الذي تخصصه منصة الاستضافة. بعد التشغيل، يكون الموقع العام متاحاً على `/` ولوحة المالك على `/admin`.

> لا ترفع ملف `.env` الذي يتضمن كلمات مرور أو مفاتيح تخزين إلى مستودع عام. احتفظ به حصراً في أسرار بيئة الاستضافة.

## ملاحظات التشغيل

تتطلب جلسات لوحة المالك HTTPS في الإنتاج. يوصى كذلك بتشغيل النسخ الاحتياطي من لوحة المالك قبل أي استيراد محتوى أو نقل لقاعدة البيانات. راجع [دليل النشر](docs/DEPLOYMENT.md) للاطلاع على متغيرات S3 وخطوات الترحيل والتحقق قبل الإطلاق.
