# تشغيل ونقل واجبات بلس

تحتوي الحزمة على موقع الزوار ولوحة المالك والخادم وقاعدة البيانات ضمن مشروع واحد. لا توجد حاجة إلى فصل واجهة أمامية أو خدمة خلفية؛ يبني الأمر `pnpm build` الواجهة والخادم معاً ثم يشغلهما `pnpm start`.

## المتطلبات

| العنصر | الحد الأدنى المطلوب |
|---|---|
| بيئة التشغيل | Node.js 22 أو أحدث وpnpm 10 |
| قاعدة البيانات | MySQL 8 أو TiDB متوافق مع MySQL |
| التخزين | S3 متوافق أو التخزين المدمج المتاح في البيئة الحالية |
| متغيرات الحماية | `DATABASE_URL` و`JWT_SECRET` وبيانات المالك الأولية |

## خطوات النقل

انسخ ملفات المشروع، ثم أنشئ ملف البيئة الخاص بخادمك وأدخل القيم الخاصة به. لا تضع ملف البيئة الذي يحتوي قيماً حقيقية داخل مستودع عام أو داخل النسخة المضغوطة المرسلة للعملاء.

```bash
pnpm install --frozen-lockfile
pnpm drizzle-kit generate
pnpm drizzle-kit migrate
pnpm build
NODE_ENV=production pnpm start
```

يجب أن يوجّه النطاق إلى عملية Node.js، مع تمرير منفذ البيئة الذي توفره منصة الاستضافة. لا يُثبت رقم منفذ في المشروع. بعد أول دخول إلى `/admin`، غيّر بيانات المالك من قسم **إعدادات حساب المالك** لإبطال أي جلسات قديمة.

## التخزين الخارجي

للتشغيل خارج البيئة الحالية، أضف القيم الستة في قسم S3 داخل إعدادات البيئة الخاصة بخادمك. يدعم المشروع AWS S3 وCloudflare R2 وMinIO وأي مزود S3 متوافق؛ و`S3_ENDPOINT` اختياري مع AWS ومطلوب غالباً مع R2 أو MinIO. يجب أن يكون `S3_PUBLIC_BASE_URL` رابطاً عاماً أو رابط CDN للـ bucket لأن الصور والملفات المحفوظة تُخزن كرابط قابل للعرض.

| المتغير | الغرض |
|---|---|
| `DATABASE_URL` | رابط اتصال MySQL/TiDB الخاص بالبيئة الجديدة. |
| `JWT_SECRET` | سر عشوائي طويل لتوقيع جلسات المالك. |
| `ADMIN_EMAIL` و`ADMIN_PASSWORD` | بيانات الدخول الأولية فقط؛ يمكن تغييرها من لوحة المالك بعد التشغيل. |
| `S3_ENDPOINT` و`S3_REGION` و`S3_BUCKET` | تعريف مزود التخزين الخارجي المتوافق مع S3. |
| `S3_ACCESS_KEY_ID` و`S3_SECRET_ACCESS_KEY` | بيانات اعتماد وصول التخزين الخارجي. |
| `S3_PUBLIC_BASE_URL` | رابط CDN أو النطاق العام للملفات المرفوعة. |

## النسخ الاحتياطي والاستعادة

يمكن للمالك تنزيل نسخة JSON من اللوحة. الاستيراد يعيد مجموعات محتوى الموقع المدارة فقط، ولا يحذف العملاء أو الطلبات أو الرسائل. ينصح بأخذ نسخة جديدة قبل الاستيراد، وبترحيل قاعدة البيانات وملفات الوسائط منفصلة عند الانتقال الكامل إلى بيئة جديدة.

## فحوص ما قبل الإطلاق

نفّذ `pnpm check` و`pnpm test`، وتحقق من تدفق تسجيل الدخول وإرسال طلب تجريبي ورفع ملف في بيئة غير إنتاجية. بعد ذلك اربط النطاق وشغّل الموقع خلف HTTPS؛ تعتمد جلسة المالك على ملفات تعريف ارتباط آمنة عند الإنتاج.
