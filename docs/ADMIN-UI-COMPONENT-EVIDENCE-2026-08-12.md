# أدلة مكونات لوحة الإدارة — 12 أغسطس 2026

## منهج الاختبار

شُغّل `scripts/browser-owner-login.mjs` بعد تسجيل الدخول الحقيقي للمالك على البيئة المحلية المتصلة بقاعدة البيانات. لم ينشئ الاختبار أي طلبات أو رسائل أو تقييمات، بل انتقل إلى بيانات موجودة فقط والتقط لقطات مرئية.

| المكوّن | الدليل الصريح | نتيجة التحقق |
|---|---|---|
| بطاقات الملخص | `desktop-dashboard.png` و`desktop-alerts.png` | ظهرت أربع بطاقات ملخص واضحة مع أرقام الزيارات والطلبات والرسائل والتقييمات. |
| جدول/قائمة الطلبات | `desktop-requests.png` | ظهرت وحدة الطلبات مع حالة «قيد المراجعة» وإجراءاتها ومحرر التحديث. |
| نموذج الإعدادات | `desktop-settings.png` | ظهرت حقول إعدادات الموقع والتنبيه الإرشادي وأزرار الحفظ بصورة منظمة. |
| الحالة الفارغة | `desktop-empty-messages.png` | انتقل الاختبار إلى وحدة الرسائل وأكد وجود `.empty` بالنص «لا توجد رسائل مطابقة للبحث أو التصفية.» |
| التنبيهات | `desktop-alerts.png` | أكد الاختبار وجود `.alert-panel` و`.alert-action`؛ وتظهر بطاقة «انتبه إلى متابعة» وإجراء «طلبات جديدة للمراجعة». |
| الهاتف | `mobile-navigation.png` | أكد فتح قائمة الهاتف الجانبية واستمرار الوصول إلى عناصر التنقل. |

> تُحفظ اللقطات في مسار الاختبار المؤقت `/tmp/wajbat-admin-redesign-evidence/` عند تشغيل السيناريو، ولا تُضاف إلى حزمة الإنتاج كي لا تتضمن أي بيانات تشغيلية.
