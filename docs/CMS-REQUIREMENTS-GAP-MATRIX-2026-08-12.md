# مصفوفة فجوات CMS ولوحة الإدارة — 12 أغسطس 2026

## نطاق الحماية

تؤكد هذه الخطة المحافظة على واجهة الزائر، الخدمات الرئيسية والفرعية، التحميلات، المقالات، التقييمات، الأسئلة الشائعة، الشركاء، بيانات التواصل، وخدمة **«إنشاء رابط»**. لن يُعاد المرشد الصوتي، وتبقى الإحصاءات محصورة في الإدارة.

| المتطلب المرفق | الوضع الفعلي | الإجراء المطلوب |
|---|---|---|
| صفحة إدارة منفصلة، RTL، Sidebar، Header، بطاقات، تنبيهات، بحث وفلاتر وهاتف | **منفذ جزئياً** | التصميم الحالي يدعم هذه الأسس؛ يستكمل الوضع الليلي والبحث/الترقيم الموحد وتحسينات الوحدات. |
| حماية الإدارة بالبريد وكلمة المرور، API محمي، انتهاء جلسة | **منفذ** | جلسة HttpOnly خادمية لمدة 12 ساعة وصلاحيات مالك. يُوثق الاختبار. |
| تغيير البريد وكلمة المرور وإبطال الجلسات الأخرى | **منفذ** | التغيير يتطلب كلمة المرور الحالية ويرفع إصدار الجلسة فيبطل الجلسات السابقة. |
| الاسم والصورة وشعار الإدارة وخلفية/ترحيب الدخول وإعدادات الأمان | **فجوة** | توسعة ملف حساب المالك وتخزين إعدادات واجهة الدخول/الإدارة في مجموعة إعدادات خادمية. |
| Passkey/WebAuthn | **مؤجل** | لا يضاف دون دورة تسجيل موثوقة وتوافق جهاز؛ يبقى الدخول بالبريد وكلمة المرور أساسياً. |
| جميع عناصر القائمة المطلوبة | **منفذ جزئياً** | الوحدات الحالية: خدمات، اشتراكات، تحميلات، مقالات، تقييمات، شركاء، أسئلة، طلبات، رسائل، وسائط، إعدادات وحساب. تضاف مفاتيح CMS المفقودة دون «إدارة ملفات» مستقلة. |
| لوحة تحكم موسعة وسجل آخر التعديلات | **منفذ جزئياً** | توجد بطاقات وتحليلات وطلبات/رسائل/تقييمات؛ يضاف عرض سجل النشاط وآخر المحتويات المطلوبة. |
| إحصاءات إدارية متقدمة | **منفذ جزئياً** | الزيارات حسب اليوم والمصدر والجهاز والطلبات موجودة؛ تتطلب مشاهدة المقالات/التحميلات نمذجة أحداث عرض/تحميل قبل تقديم أرقام حقيقية. |
| محرر الصفحة الرئيسية والتصميم دون كود | **فجوة جزئية** | المحتوى الحالي قائم على مجموعات؛ يستبدل التحرير الخام بنماذج منظمة مع معاينة قبل الحفظ. |
| رفع الصور والملفات وربطها بالمحتوى | **منفذ جزئياً** | يوجد رفع خادمي ومكتبة وسائط وشعار؛ تُضاف أزرار اختيار وربط وسائط إلى المحررات الجديدة. |
| معاينة الموقع كزائر والعودة للإدارة | **منفذ جزئياً** | يوجد زر معاينة في الشريط؛ يضاف مسار عودة ظاهر لا يظهر للزوار. |
| ترتيب Drag & Drop وترقيم | **فجوة** | الترتيب الحالي أزرار صعود/هبوط؛ يتحول إلى ترتيب بالسحب ضمن المجموعات المدعومة، والترقيم يضاف للقوائم الكبيرة. |
| نسخ احتياطي واستعادة | **منفذ** | تصدير/استيراد JSON للمحتوى مع سجل تدقيق. |

## أولويات التنفيذ

1. **عدم المساس بواجهة الزائر والبيانات القائمة**، مع أخذ نسخة محتوى قبل أي توسعة.
2. توسيع مفاتيح المحتوى والمحررات المنظمة للوحدات الإدارية الناقصة.
3. إضافة إعدادات حساب وهوية الإدارة ومعاينة قبل الحفظ، ثم تحسين القائمة والتحكم والإحصاءات.
4. اختبار كل حفظ ورفع ومعاينة من خلال الخادم وتوثيق النتائج دون بيانات تجريبية.
