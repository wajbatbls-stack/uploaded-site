# معمارية واجبات بلس الموسعة

## المبدأ التشغيلي

يحافظ الموقع العام على واجهته الحالية ومساراته وتجربة الزائر، بينما تصبح البيانات والعمليات الإدارية داخل قاعدة البيانات وواجهة `/admin` المحمية. تعتمد كل واجهات الإدارة على جلسة مالك موقعة داخل ملف تعريف ارتباط `HttpOnly`، ولا تظهر أي روابط إدارية في الموقع العام.

## نموذج البيانات

| النطاق | التخزين | الغرض |
|---|---|---|
| المحتوى العام | `content_collections` | الخدمات، الباقات، المقالات، الأسئلة، الشركاء، التنزيلات، الإعدادات وSEO |
| حساب المالك | `owner_accounts` | بريد المالك وكلمة المرور المشفّرة وآخر تعديل، مع استخدام متغيرات البيئة كبذرة أولى فقط |
| الطلبات | `assignment_requests` | بيانات الطلب، الحالة، الملف المرفق، الملاحظات وتاريخ الإنشاء |
| العملاء | `customers` | تجميع الطلبات حسب البريد أو الجوال لعرض سجل العميل |
| الرسائل | `contact_messages` | رسائل التواصل وحالة المعالجة |
| التقييمات | `student_reviews` | التقييمات المعلقة والمنشورة والمخفية |
| الملفات | `media_files` | وصف الملفات المخزنة في التخزين الخارجي والرابط والنوع والحجم والاستخدام |
| النشاط | `admin_audit_events` | العمليات الحساسة للمراجعة، مثل تغيير حالة طلب أو بيانات الحساب |

## الحدود الأمنية

تتحقق جميع عمليات الإدارة في الخادم عبر `ownerProcedure`. يقتصر رفع الملفات على أنواع مسموحة، وحجم محدد، ومسارات تولّد في الخادم. لا يُحفظ الملف الخام أو كلمة المرور كنص صريح داخل قاعدة البيانات أو الواجهة. يستمر استخدام قيم `ADMIN_EMAIL` و`ADMIN_PASSWORD` كبذرة متوافقة عند بدء التشغيل، ثم يمكن للمالك تغيير بياناته من قسم الحساب.

## النقل والنسخ الاحتياطي

توفر لوحة الإدارة تصديراً منظمًا بصيغة JSON للمحتوى والإعدادات والكيانات الإدارية القابلة للاستيراد. الملفات نفسها تبقى في تخزين كائنات منفصل مع بياناتها الوصفية، ويشرح `DEPLOYMENT.md` متطلبات قاعدة البيانات والمتغيرات البيئية وتخزين الملفات لتشغيل نسخة مستقلة لاحقاً.
